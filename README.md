La web de referencia tiene estas características clave que debemos replicar:

1. Layout & Estructura

Una sola página (single page) con scroll suave

Secciones claramente delimitadas con padding y márgenes generosos

Jerarquía visual fuerte (títulos grandes, subtítulos medianos, texto pequeño)

Espacios en blanco estratégicos para respirar

2. Tipografía & Color

Fuente principal: Inter, Roboto o Helvetica (limpia y moderna)

Fuente secundaria: Una serif elegante para títulos (como Playfair Display)

Paleta de colores: 2-3 colores + neutros

Principal: Negro/gris oscuro (#1a1a1a)

Acento: Color vibrante (ej: #4a90e2 o #ff6b6b)

Neutros: Blanco, gris claro (#f5f5f5)

3. Efectos & Interacciones

Scroll animado: Parallax sutil, elementos que aparecen al hacer scroll

Hover effects: Zoom en imágenes, cambios de color en botones

Transiciones suaves: Entre secciones, en menú

Video backgrounds: Para destacar proyectos clave

4. Responsive & Performance

Mobile-first: Diseño adaptado primero a móvil

Imágenes optimizadas: WebP, lazy loading

CSS/JS minificados: Para cargar rápido
